Detailed Description

Main menu for GRID WARS, a collection of Tic-Tac-Toe variants.

This program allows the user to select from multiple Tic-Tac-Toe games, set up players, run the selected game, and clean up resources afterward.

Function Documentation

◆ main()

int main ( )

Entry point for the GRID WARS program.

This function runs the main loop that allows the user to:

  1. Choose a game from the menu.
  2. Set up the players.
  3. Run the selected game using the appropriate GameManager.
  4. Clean up all allocated resources.

The loop continues until the user chooses to exit (option 0).

Returns
int Returns 0 upon program exit.
