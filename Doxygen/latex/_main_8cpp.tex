\doxysubsection{Detailed Description}
Main menu for GRID WARS, a collection of Tic-\/\+Tac-\/\+Toe variants. 

This program allows the user to select from multiple Tic-\/\+Tac-\/\+Toe games, set up players, run the selected game, and clean up resources afterward.
