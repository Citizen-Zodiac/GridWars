\doxysubsection{Detailed Description}
Logic handler for the Numerical Tic-\/\+Tac-\/\+Toe board. 

This class manages\+:
\begin{DoxyItemize}
\item Tracking used numbers.
\item Updating the board after valid moves.
\item Determining win/lose/draw conditions. 
\end{DoxyItemize}
