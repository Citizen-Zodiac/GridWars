\doxysubsection{Detailed Description}
Specialized board class for the Misere game. 

This class inherits from the generic {\ttfamily \doxylink{class_board}{Board}\texorpdfstring{$<$}{<}char\texorpdfstring{$>$}{>}} class and implements the specific logic required for Misere, including move updates and win/loss/draw conditions.
