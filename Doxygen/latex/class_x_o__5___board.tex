\doxysubsection{Detailed Description}
Specialized board class for the XO (5x5) game. 

This class inherits from the generic {\ttfamily \doxylink{class_board}{Board}\texorpdfstring{$<$}{<}char\texorpdfstring{$>$}{>}} class and implements the specific logic required for XO (5x5), including move updates and win/loss/draw conditions.
