\doxysubsection{Detailed Description}
Specialized board class for the Connect Four game. 

This class inherits from the generic {\ttfamily \doxylink{class_board}{Board}\texorpdfstring{$<$}{<}char\texorpdfstring{$>$}{>}} class and implements the specific logic required for Connect Four, including move updates and win/loss/draw conditions.
