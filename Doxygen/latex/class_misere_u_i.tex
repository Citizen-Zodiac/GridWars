\doxysubsection{Detailed Description}
User interface class for the Misere game. 

This class inherits from the generic {\ttfamily \doxylink{class_u_i}{UI}\texorpdfstring{$<$}{<}char\texorpdfstring{$>$}{>}} class and implements methods for player setup and move retrieval specific to the Misere game.
